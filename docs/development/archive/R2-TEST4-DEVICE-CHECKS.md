# XHYN IV R2 Test 4: phone checks

Package `com.xhyn.ivrecomp`, version `0.5.9.3-xhyn-r2-test4`, code 32. It is signed with the original release certificate and can be tested as an update. This is a test candidate, not a published release.

Start on the existing Adreno 750 installation and retain your current graphics/driver settings for the first run. Export saves before testing save-management operations. The app preserves existing custom settings; use Reset in the relevant settings category when deliberately testing recommended defaults.

1. **Achievements:** confirm the existing 1/65 record is visible. If no catalog exists, use Prepare achievement list without entering gameplay. Check locked/unlocked filters, secret preference, icons, dates and a legitimate new unlock. Quit normally and reopen the launcher. Repeat a full backup/restore and confirm the card refreshes.
2. **Mouse:** use Play with logs and input tracing for a short test. Check camera motion, LMB/RMB, wheel, sensitivity/inversion, driving, map/menu, focus loss, pause/resume, disconnect/reconnect and keyboard/touch/controller combinations. Test USB and Bluetooth separately.
3. **Restart settings:** change GPU Turbo or compatibility mode plus a live setting, save, choose Later, reopen settings and confirm the queued value remains. Quit normally and start again. Confirm the pending marker clears and effective settings agree. Repeat Quit now after saving game progress.
4. **Controls/editor:** enter the same context from launcher and game. Check camera/focus/radio/radar/map controls, grid sizes, snapping, numeric position/scale/opacity, hide/show, undo/redo, context reset and profile round trip. Confirm other contexts and the other layout type remain intact. Check translucent camera glyphs and existing aim-lock/gyro behavior.
5. **Menus/overlay:** inspect the launcher gap, overflow, footer, card and log action row. Check single-line session statistics, Diagnostics-only details, return navigation, entrance/exit motion and Reduce motion. Try centered/custom overlay positions, size/opacity and memory/thermal toggles with larger system text.
6. **Save packages:** back up two distinct slots. Restore one and load both in game. Delete only an expendable copied slot, then restore its recovery copy. Other packages and achievements must remain unchanged. File/package names are not certified human-readable episode/slot metadata.
7. **Completion:** compare any Last observed percentage and episode against the game's Statistics on two saves. Load another slot and allow at least 30 seconds before normal quit. No value, an incorrect value or a stale historical value should be reported; it is not yet certified per-slot completion.
8. **Pipeline preparation:** compare cold and warm compatible caches on the same route. Test 0/3/5-second budgets, Skip, backgrounding and a changed driver/AA setting. Record preparation duration and later compilation waits. Known-work completion must not imply all possible shaders are prepared.
9. **Graphics:** compare Native/FSR, Off/FXAA/SMAA, VSync requested versus actual, shadows, mirrors/water/transparency, TLAD grain and dithering. The TV behavior is a regression check only; the user confirmed it already works.
10. **Drivers:** keep the existing driver first, then compare the separately named bundled V38. Confirm actual GPU/driver status, fallback and settings before benchmarking. The bundled Xclipse driver is for admitted Xclipse devices on Android 14+, not this Adreno phone. Do not infer A710/Mali/Xclipse support from an A750 run.
11. **Storage/mods:** test accessible-folder selection with sufficient space, retained originals and launch/DLC access. SAF selection performs a copy. Use one reversible compatible loose-data mod at a time, confirm overlay order and Off behavior, and verify original files remain unchanged. PC plugins/FusionFix DLLs are outside support.
12. **Sustained behavior:** compare 15–20 minute runs from similar temperatures, same save/route/cap/driver and cold/warm-cache state. Compare Thermal Guard and optional texture retention separately. Record late-session pacing, PSS, thermal severity, visible changes and audible dropouts. Keep short detailed profiling separate from the clean benchmark.
13. **Controller/map:** connect two controllers in different orders, reconnect and combine with touch. Verify player one and offline saving/loading. Compare cursor/waypoint/landmark/radar at minimum/maximum zoom, Native/FSR and different output/render resolutions.
14. **Other GPUs:** capture the exact driver/device feature report before testing. On a device lacking depthClamp, inspect near-plane geometry, cutscenes, shadows and mirrors with the experimental fallback. Missing shaderInt64 or unsupported user clipping can still block rendering. Xclipse RADV and 16-location remapping need actual startup and sustained-route tests.

Useful feedback is the exported log ZIP, exact steps, settings/driver identity and a brief clip or screenshot showing any visual/input issue. Collision or guest-call crashes need the matching report, route/mission and valid game-data identity before a targeted repair.
